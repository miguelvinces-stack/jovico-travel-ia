        Zona Pedagógica
        
Fundamentos de IA Generativa en Producción

        

          Comprende las diferencias esenciales, costos y casos de uso entre las tres estrategias fundamentales para adaptar Modelos de Lenguaje (LLMs).
        

      


      

        
        
        

          

            

              
            

            
1. Prompt Engineering & CoT

            Ingeniería de Instrucciones
            

              Consiste en diseñar directivas claras, delimitadores, roles y técnicas de razonamiento explícito como Chain-of-Thought (CoT) para guiar la inferencia sin alterar los pesos del modelo.
            

            

              

                 Ventajas:
              

              
Sin costo de entrenamiento, implementación instantánea y máxima flexibilidad.

            

          

          

            Cuándo usar: Tareas generales, formateo estructurado, razonamiento lógico y prototipado rápido.
          

        


        
        

          
            Usado en esta App
          
          

            

              
            

            
2. RAG (Generación Aumentada)

            Recuperación + Inferencia
            

              Recupera datos precisos de una base de conocimiento externa (CSV, SQL o base vectorial) y los inyecta dinámicamente en la ventana de contexto del LLM antes de formular la respuesta.
            

            

              

                 Ventajas:
              

              
Elimina alucinaciones fácticas, cita fuentes verificables y no requiere reentrenar.

            

          

          

            Cuándo usar: Datos privados, información dinámica, catálogos turísticos o documentos corporativos.
          

        


        
        

          

            

              
            

            
3. Fine-Tuning

            Ajuste Fino de Pesos
            

              Re-entrena supervisadamente los pesos internos de la red neuronal mediante miles de pares de ejemplos (input-output) para que aprenda un estilo, tono o sintaxis altamente especializada.
            

            

              

                 Consideración:
              

              
No es el método adecuado para enseñar datos fácticos nuevos, sino estilos o formatos fijos.

            

          

          

            Cuándo usar: Estilo de marca estricto, lenguajes médicos/legales muy técnicos o reducción drástica de tokens.
